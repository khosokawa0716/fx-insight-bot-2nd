# 仮想通貨AI自動売買システム：プロジェクト定義書（全体像）

## 1. プロジェクトの最終目的
GMOコインのビットコイン（BTC/JPY）市場において、**「テクニカル指標」と「AI（機械学習）」を組み合わせた、リスク回避型の自動売買システム**を構築し、GCP上で24時間稼働させること。

## 2. システムのコア・ロジック（メタラベリング戦略）
方向予測とリスク管理の役割を完全に分離する。

* **役割①：方向の決定（テクニカル指標）**
  * AIは使わず、固定のルール（RSIやMACDなど）で「買い（Buy）」「売り（Sell）」の1次シグナルを発生させる。
* **役割②：確信度の判定とロット制御（AI）**
  * AIは「これから上がるか下がるか」ではなく、**「役割①のシグナルが成功する確率（勝率）」**を予測する。
  * AIの予測確率に基づいて、発注するロットサイズを動的に変更する。
    * 確率 低：ロット 0 （見送り：負けトレードを回避する）
    * 確率 中：ロット 500 / 1000
    * 確率 高：ロット 1500

## 3. 取引の実行ルール
* **注文方式**: IFDOCO注文（エントリーと同時に、利益確定と損切りの決済注文を出す）
* **決済基準**: 利確（TP）40pips / 損切（SL）40pips の固定幅。
  * ※バックテスト時、AIには「先にTPに到達したら成功(1)、SLに到達したら失敗(0)」として学習させる。

## 4. AIに与えるデータ（優位性の源泉：特徴量）
AIが勝率を予測するための「相場のヒント」として、Tickデータ（全約定履歴）から以下の数値を1分足ごとに計算して入力する。
* **基本指標**: 始値・高値・安値・終値・出来高
* **VWAP**: 出来高加重平均価格（大口の平均取得単価の目安）
* **Imbalance**: 総出来高に対する「買い」の比率（売買の偏り）
* **シャノン・エントロピー**: その1分間の約定サイズ（数量）の無秩序度。大口のアルゴリズムが作る「不自然な秩序」を検知するための独自指標。

## 5. インフラ構成（予定）
* **フェーズ1（完了）**: 手元のPC（Python）にて、過去のCSVデータを用いて指標計算と出力確認を行った。
* **フェーズ2（現在ここ）**: 手元のPC（Python）にて、バックテストを行い、ロジックが本当に勝てるか（優位性）を検証する。
* **フェーズ3・4（将来）**: GCP上に構築。Cloud Runで24時間通信・発注を行い、BigQueryにデータを蓄積し、Vertex AIで推論・再学習を行う。

## 6. BigQueryについての方針メモ
* **用途**: 自動売買が実際に動き始めてから蓄積される取引ログの保存・分析基盤。モデルバージョンごとの成績比較や、気になる切り口での随時分析に使う。
* **導入タイミング**: Phase 3（GCPインフラ構築）のタイミングで導入する。Phase 2 完了前に入れても分析対象の取引ログが存在しないため、不要。
