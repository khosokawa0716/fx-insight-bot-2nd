# バックテスト試行ログ

試行結果を記録し、シグナル選定の根拠を残す。

## 見方

- **勝率の目安**: 53〜56% が現実的な期待値。50% 以下はランダム以下。
- **PF の目安**: 1.0 以上でプラス収支。1.2 以上で優位性ありと判断。
- **取引回数**: 月30回未満は統計的に参考程度。100回以上あると信頼度が上がる。
- **怪しいサイン**: 勝率が高すぎる（70%超）・取引回数が極端に少ない・特定月だけ良い。

## 気づき・議論メモ

- 全期間で検証するほど過剰適合のリスクは下がるが、消えない
- 取引回数が少ないと勝率の信頼性が低い（30回未満は参考程度）
- 単純なシグナルで高勝率が出たら陳腐化の可能性を疑う（市場効率性）
- 1次シグナルは「ランダムより少しマシ」で十分。精度の向上はAIの役割
