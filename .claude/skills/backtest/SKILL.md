以下の手順でバックテストを実行し、結果を記録・コミットしてください。

## 引数の確認

ユーザーのメッセージから以下を読み取る。指定がなければ質問して確認する。
- `--year`（例: 2021）
- `--month`（例: 5）
- `--signal`（baseline / rsi / ma / macd）
- `--verbose`（「中間値も見たい」などの指示があれば付ける）
- 考察メモ（任意。ユーザーが「〜を確認したい」などと言っていれば記録する）

## 手順

1. バックテストを実行する：
```
.venv/bin/python backtest.py --year <year> --month <month> --signal <signal> [--verbose]
```

2. 出力から以下を読み取る：
   - 取引回数
   - 勝率（例: 51.0%）
   - PF（例: 1.041）

3. `docs/backtest_log.md` の試行履歴テーブルに1行追記する：
   - `#` は既存の最大番号+1
   - 日付は今日の日付
   - シグナル名と条件は簡潔に（例:「MACDクロス」「RSI≤30/≥70」）
   - 考察欄：ベースラインとの比較、取引回数の評価、気になる点などを1〜2文で書く

4. グラフを更新する：
```
.venv/bin/python backtest.py --plot
```

5. コミットする（commitスキルに従う）：
   - コミット対象: `docs/backtest_log.md` と `output/backtest_chart.png`
   - メッセージ例: `docs: <signal>シグナルのバックテスト結果を追記 (<year>/<month>)`

6. 結果をユーザーに報告する。ベースラインとの差分を必ず含める。
